# DAPH V2B Review-Lite Branch

This branch is a NON-AUTHORITATIVE review mirror of `v2b-infrastructure`.
Large generated scientific artifacts are intentionally omitted, including:
- historical evidence bundles
- exhaustive oracle tables
- distribution archives
- large generated caches

The authoritative scientific artifacts remain on:
`v2b-infrastructure`

Authoritative source identity:
- commit: `810047cdf639b57d4e89f899f38f0de009511712`
- tree: `ce805a9ab5ac6816e9c81e5d32ab12d511e1273b`

The exact artifacts omitted, with their paths, SHA-256 hashes, and sizes,
are recorded in `LARGE_ARTIFACTS.json`. A reviewer who needs to inspect a
canonical artifact can read it directly from `v2b-infrastructure` at the
commit above.

This branch is intended for source-code review, architecture analysis,
unit-test inspection, and benchmark-methodology review only. It must
never be used for qualification.
